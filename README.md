# AIR_CANVAS_2026
 Air Canvas – Computer Vision & Gesture-Based Digital Drawing Tool

Engineered a real-time air-drawing application in Python using OpenCV and MediaPipe to track hand gestures via webcam for touchless digital canvas interaction.

Implemented MediaPipe Hand Tracking to detect hand landmarks, enabling real-time fingertip trajectory mapping and gesture-based drawing/erasing capabilities.

Designed custom canvas overlay algorithms to render smooth lines and dynamic color selections directly on live video feeds with minimal latency.

Integrated visual control panels and gesture triggers for seamless color switching, clearing canvas state, and saving canvas snapshots locally.
